Policies

Every rule the platform actually enforces, in one place — each one is implemented in exactly one spot in the code, so this list can't drift out of sync with what the app does.

$60/day spending limit

Any day whose total (converted to USD) exceeds $60 is flagged for review — except a day that includes a Flight or Hotel charge, which routinely clears $60 on its own and isn't a policy question the way an unusual day of meals or taxis would be. That day is still shown, just not as a violation.

Currency (USD / MXN)

Employees pick the currency a receipt was actually issued in. MXN amounts are converted to USD at a fixed rate (17 pesos per dollar) for the $60/day check and every report total — the original peso amount is never altered, only used for comparison. Update the rate in one place (expenses/policies.py:USD_MXN_RATE) if it moves.

30-day submission deadline

A report must be submitted within 30 days of the trip's flight date (or its earliest document date, if there's no flight). Past that, the employee can't submit it — the documents stay on the report as a draft.

One report = one trip (21-day span)

Every document on a report must fall within 21 days of the others. Receipts from two unrelated trips can't be combined into one report.

4-page PDF limit

An uploaded PDF receipt can't exceed 4 pages. The amount/type auto-detection only searches the first 2 pages.

CEO approval clause

An admin can't approve a report without explicitly checking the box confirming the approval is issued under the CEO's delegated authority (Steffan Widmer). Rejecting doesn't require this, but does require a note explaining why.

File retention

Original receipt files (PDFs/photos) are deleted once a report is approved — the generated Excel and Word become the permanent record instead (with a receipt capture image embedded for every document, not just photos). A report that's never approved (still pending, or rejected) keeps its originals until they're 90 days old, at which point a scheduled cleanup job removes them automatically (the report and its data stay — only the file goes). See docs/DEPLOYMENT.md for how that job is scheduled.

Department-scoped approval

An HR/general admin sees and approves every department's reports. A department admin only sees and approves their own department's — never another's, even by guessing a report's URL directly.

Account lockout

3 consecutive failed login attempts on an email locks that account out, even with the correct password afterward. A password reset lifts the lockout.

Signup is open — admin access is not self-service

Any employee can create their own account at /accounts/signup/, no invitation needed — that's by design, so onboarding doesn't bottleneck on an admin. Admin access is different: there's no self-service "request admin" button on purpose. An employee who needs it asks personally — Iris Cortez, Adrian Heymes, Karen Plascencia, or Steffan Widmer (CEO) — and one of them grants it from the Users & Groups tab (is_staff, and either is_superuser or a supervised_department).

Help & FAQ

Common questions while reviewing reports — what to do, and exactly where to click.

A report shows a red "$60/day" flag, but it's a flight or hotel day — is that a problem?
No action needed. Flight/hotel days are shown in blue as informational, never as a violation — only a genuinely unexplained day (no flight/hotel, still over $60) shows red. See the Policies tab.
Where do I download the final Excel/Word for an approved report?
Open the report → Summary tab (the first one) → the green/gray box at the top has the download buttons. Before approval, the same box lets you preview a live version instead.
How do I approve or reject a report?
Open the report → Review tab → set Status, add a note (required to reject), check the CEO clause box (required to approve) → Save.
A document's file link says "(archived)" — where did it go?
The report was approved, which deletes original files by design (see Policies → File retention). The data is still there; download the Summary tab's Excel/Word for the permanent record, which includes an image capture of every receipt.
How do I find a specific employee?
Go to the Employees tab and type their name or department in the search box — every employee registered on the platform is listed, not just ones with a report.
I only see some departments' reports, not all of them — is that a bug?
No — that's department-scoped access working as intended (see Policies). Only the HR/general admin account sees every department.
I'm locked out after failed login attempts — what do I do?
Use "Forgot your password?" on the login page. Completing a password reset lifts the lockout automatically.
Where can I see a report's full history — who did what, and when?
Open the report → History tab (the last one) — every action (created, documents uploaded, submitted, approved/rejected) with who did it and when.
Someone new needs admin access — where's the "make admin" button?
There isn't one on purpose. Have them ask Iris Cortez, Adrian Heymes, Karen Plascencia, or Steffan Widmer (CEO) personally, then grant it yourself from Users & Groups → open their account → check is_staff, and set either is_superuser (general admin) or supervised_department (department admin) — never both.
